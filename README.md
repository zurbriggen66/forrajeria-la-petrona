# forrajeria-la-petrona

Sistema de gestión para Forrajería La Petrona.

## Estructura

- `backend/` — API en Django + Django REST Framework.
- `frontend/` — aplicación en React + Vite.

## Backend

```
cd backend
./venv/Scripts/activate
python manage.py runserver
```

## Frontend

```
cd frontend
npm install
npm run dev
```
